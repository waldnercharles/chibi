**Contract implemented (docs/recoverable-errors.md, worktree protocol14):** operations return ordinary named values followed by a typed optional error (`-> (data: u8[], error: DecodeError?)`), nil = success. A package-owned struct or union marked `@error` is an error type; any callable whose final result can directly contain one must have that result acknowledged (check, report, return, pass or store). Reading only sibling outputs, unused aliases and overwrites do not acknowledge. Ordinary `T?` absence is unaffected. No exceptions, generic `Result`, propagation operator, sibling-success gate, optional-syntax migration or general return inference. Old function-level `@fallible` is rejected. Public package-compiler `Compile`/`CompileWithEffects`/`CompileBehavior` now return `(module: u64, bytes: u8[], error: syntax.Diagnostic?)`; asset facade returns `(entry_id, prepared, error)`; closure byte entry points and the 29-byte asset transport are unchanged. Runtime ABI unchanged; grammar parser ABI stays 15 (rules/states changed; `src/language/src/parser.c` regenerated with Tree-sitter 0.25.10 - never hand-edit).
