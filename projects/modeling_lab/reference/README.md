# Polaroid OneStep modeling reference

`polaroid-onestep.jpg` is the original 2,560 × 1,920 photograph **Polaroid OneStep** by **Mike W. (squeakymarmot), Vancouver, Canada**, photographed 16 March 2007.

- Source and attribution record: <https://commons.wikimedia.org/wiki/File:Polaroid_OneStep.jpg>
- Original photographer page: <https://www.flickr.com/photos/squeakymarmot/429058439/>
- Original image: <https://upload.wikimedia.org/wikipedia/commons/8/88/Polaroid_OneStep.jpg>
- License: **Creative Commons Attribution 2.0 Generic**, <https://creativecommons.org/licenses/by/2.0/>

The original photograph is reproduced without modification. `polaroid-onestep-1280.jpg` is [Wikimedia's 1,280 pixel thumbnail](https://upload.wikimedia.org/wikipedia/commons/thumb/8/88/Polaroid_OneStep.jpg/1280px-Polaroid_OneStep.jpg), used within the renderer's existing 2,048 pixel image limit. The new procedural 3D reconstruction is derived by visual inspection of this single image. Its unseen surfaces are inferred. The thumbnail is copied into `content/images/PolaroidReference.jpg` for the two small printed nameplates; their material samples only those badge regions using projective UV coordinates. Housing, controls, optics, silhouette, and depth are construction geometry.
