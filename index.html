Chibi

Chibi is a language and runtime for games. Write game behavior in .chibi files. Define scenes, components and resources in text files. Run the game with chibi run.

  • Language: learn the syntax through code.
  • Examples: try common game programming tasks.
  • Toolchain: build, run and export a project.
  • Testing: check package functions with @test.

Install

Native builds need CMake, a C23 compiler and libclang for reflection. Run these commands from the engine checkout:

make install
export PATH="$HOME/.local/bin:$PATH"
chibi doctor

The default install directory is ~/.local. Use make install PREFIX=/absolute/prefix to select another directory. The SDK includes the chibi command, compiler, player, headers and libraries.

For a development build, use make build. Run the command as build/sdk/chibi.

Run a project

Give chibi run a project folder or its project.kdl:

chibi run /path/to/game

Inside a project folder, omit the path:

chibi check
chibi run
chibi export --output /path/to/release

run builds changed content before it starts the player. export creates a folder or app with the player and the game's resources. See Export a game for platform details.

Edit with Studio

Studio edits the same project files. Install it from its separate checkout:

make -C /path/to/chibi-studio install
chibi-dev /path/to/game

You can also open Studio in your browser. The browser version uses the latest engine release.
