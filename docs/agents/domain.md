# Domain docs

This is a single-context repository.

Read the root `CONTEXT.md` before exploring. Read relevant documents under
`docs/adr/` when they exist. Use the glossary vocabulary from `CONTEXT.md`
consistently. Keep `CONTEXT.md` implementation-free; record implementation
decisions in ADRs only when they are hard to reverse, surprising without context,
and the result of a meaningful trade-off.
