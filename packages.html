The core packages

Each package's declarations and the comments written above them in its source.

strings

Import it as core:strings.

ByteLength

ByteLength :: (value: string) -> int

Compiler text operations use bytes, including bytes inside UTF-8 sequences.

ByteAt

ByteAt :: (value: string, index: int) -> int

Returns -1 outside the string; valid bytes are unsigned values from 0 to 255. Each call measures the string, so a loop over a long one should read Bytes.

Bytes

Bytes :: (value: string) -> int[]

Every byte of the string, from 0 to 255, read in one pass.

Slice

Slice :: (value: string, start: int, count: int) -> string

Start clamps to the string and count clamps to its remaining bytes.

Compare :: (left: string, right: string) -> int

LastIndexByte

Index

Index :: (s: string, substr: string) -> int

Rabin-Karp with Odin's 32-bit rolling hash, kept in int64 and masked; pow is the prime to the substring's length. An empty substring is found at 0.

LastIndex

LastIndex :: (s: string, substr: string) -> int

Index's search from the end. An empty substring is found at the length of s.

IndexAny

IndexAny :: (s: string, chars: string) -> int

The offset of the first byte of s that is any byte of chars.

LastIndexAny

LastIndexAny :: (s: string, chars: string) -> int

Count

Count :: (s: string, substr: string) -> int

Non-overlapping occurrences. An empty substring occurs at every byte boundary, one more than the byte length.

TruncateToByte

TruncateToByte :: (s: string, c: int) -> string

Everything before the first c, or all of s when c is absent.

EqualFold

EqualFold :: (u: string, v: string) -> bool

ASCII letters match in either case; every other byte must be equal.

ToLower

ToLower :: (s: string) -> string

ASCII letters only; other bytes, including those of UTF-8 sequences, stay.

ToUpper

ToUpper :: (s: string) -> string

IsAsciiSpace

IsAsciiSpace :: (c: int) -> bool

Tab, line feed, vertical tab, form feed, carriage return and space.

TrimLeft

TrimLeft :: (s: string, cutset: string) -> string

Removes the leading bytes that are bytes of cutset.

TrimRight

TrimRight :: (s: string, cutset: string) -> string

Trim :: (s: string, cutset: string) -> string

TrimLeftSpace :: (s: string) -> string

TrimSuffix

TrimSuffix :: (s: string, suffix: string) -> string

Cut

Cut :: (s: string, offset: int, count: int) -> string

The count bytes from offset, or all bytes from offset when count is below 1. As in Odin, an offset outside s keeps all of s, and a count past the end keeps the rest.

SplitKeeping

SplitKeeping :: (s: string, sep: string, keep: int, n: int) -> string[]

Odin's _split: at most n parts, or every part when n is negative; the last part holds the rest of s. Each other part keeps the first keep bytes of the separator after it. An empty separator splits s into bytes.

Split :: (s: string, sep: string) -> string[]

SplitLinesKeeping

SplitLinesKeeping :: (s: string, keep: int, n: int) -> string[]

Splits at line feeds; a line that ends in a carriage return loses it.

Fields

Fields :: (s: string) -> string[]

The runs of bytes between ASCII spaces.

Join

Join :: (a: string[], sep: string) -> string

Concatenate

Concatenate :: (a: string[]) -> string

Repeat

Repeat :: (s: string, count: int) -> string

Doubles what it has built, as Odin copies. Where Odin panics on a negative count, a count below 1 gives an empty string, as Slice clamps counts.

Replace

Replace :: (s: string, old: string, new: string, n: int) -> string

Replaces the first n non-overlapping matches of old, or all of them when n is negative. An empty old matches at every byte boundary.

ReplaceAll

ReplaceAll :: (s: string, old: string, new: string) -> string

Partition

Partition :: (str: string, sep: string) -> Parts

The text before the first sep, sep and the text after it; when sep is absent, head is all of str and the others are empty.
