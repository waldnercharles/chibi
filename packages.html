The core packages

Each package's pub declarations and the comments written above them in its source.

strings

Import it as core:strings.

ByteLength

pub ByteLength :: (value: string) -> int

Compiler text operations use bytes, including bytes inside UTF-8 sequences.

ByteAt

pub ByteAt :: (value: string, index: int) -> int

Returns -1 outside the string; valid bytes are unsigned values from 0 to 255. Each call measures the string, so a loop over a long one should read Bytes.

Bytes

pub Bytes :: (value: string) -> int[]

Every byte of the string, from 0 to 255, read in one pass.

Slice

pub Slice :: (value: string, start: int, count: int) -> string

Start clamps to the string and count clamps to its remaining bytes.

Index

pub Index :: (s: string, substr: string) -> int

Uses a 32-bit Rabin-Karp rolling hash. An empty substring is found at 0.

LastIndex

pub LastIndex :: (s: string, substr: string) -> int

Index's search from the end. An empty substring is found at the length of s.

IndexAny

pub IndexAny :: (s: string, chars: string) -> int

The offset of the first byte of s that is any byte of chars.

LastIndexAny

pub LastIndexAny :: (s: string, chars: string) -> int

Count

pub Count :: (s: string, substr: string) -> int

Non-overlapping occurrences. An empty substring occurs at every byte boundary, one more than the byte length.

TruncateToByte

pub TruncateToByte :: (s: string, c: int) -> string

Everything before the first c, or all of s when c is absent.

EqualFold

pub EqualFold :: (u: string, v: string) -> bool

ASCII letters match in either case; every other byte must be equal.

ToLower

pub ToLower :: (s: string) -> string

ASCII letters only; other bytes, including those of UTF-8 sequences, stay.

Cut

pub Cut :: (s: string, offset: int, count: int) -> string

The count bytes from offset, or all bytes from offset when count is below 1. An offset outside s keeps all of s. A count past the end keeps the rest.

Repeat

pub Repeat :: (s: string, count: int) -> string

Doubles the result until it reaches the requested length. A count below 1 gives an empty string.

Replace

pub Replace :: (s: string, old: string, new: string, n: int) -> string

Replaces the first n non-overlapping matches of old, or all of them when n is negative. An empty old matches at every byte boundary.

Partition

pub Partition :: (str: string, sep: string) -> Parts

The text before the first sep, sep and the text after it; when sep is absent, head is all of str and the others are empty.
