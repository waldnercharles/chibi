Studio components

Behavior follows Base UI contracts; anatomy and tokens follow shadcn; density and editor idioms follow Blender; the palette follows cmdk; numeric tuning follows DialKit. Every rule here is written in the RCSS-portable subset and uses Base UI's data-* state names, so the RmlUi port uses the same selectors.

Tokens

shadcn semantic roles · Blender surfaces

Surfaces step from --app (gaps between areas) to --field. Numeric controls and buttons are light fields; typed text is a dark input (Blender). One accent carries selection, fills and focus. Viewport selection uses Blender's orange so it stays distinct from UI selection. Instance overrides use teal. In RCSS, declare these on body (no :root) and write durations in seconds.

Icons

Nerd Font Symbols (Codicons, Material Design)

Icons are glyphs from third_party/fonts/nerd-fonts-symbols-only, the font the editor already embeds. RmlUi renders them as text in the Symbols family. 14 px in controls, 16 px in tools.

Button

shadcn Button variants · Base UI Toggle for pressed state

Variants: ghost (default), subtle, primary, outline, danger. Sizes: --h 22, --h-sm 18, icon-only square. Hover and press use translucent overlays so buttons work on any surface. Toggle buttons expose data-state=on. Pointer press feedback 110 ms; keyboard activation is immediate. Disabled uses data-disabled (RmlUi :disabled only exists on form controls).

Toggle group

Base UI ToggleGroup · Blender expanded enum

Single-value enums with up to three options render expanded. Roving focus: ← → move and select. The pressed segment is data-pressed.

Number field

Base UI NumberField + ScrubArea · Blender number field · DialKit

The whole field is the scrub area. Press and move ≥ 3 px to scrub with pointer lock at 2 px per step; release commits once (one undo step). A click without movement enters text editing with the value selected; Enter commits, Esc restores, Tab commits and edits the next field. Expressions such as *2 or =pi/4 evaluate. One modifier rule everywhere: Alt smallStep ×0.1, Shift largeStep ×10, Ctrl snap. Hover shows step arrows (hold repeats after 400 ms every 60 ms). Hover ⌘C/⌘V copies and pastes the value; Backspace resets an override. onChange(value, reason) is live; onCommit(value, previous, reason) writes history. States: data-scrubbing, data-editing, data-invalid, data-readonly, data-disabled, data-overridden.

Vector field

Blender joined vector

Components share one control with 1 px joins; axis addons use the viewport axis colors. Each axis is an independent NumberField with its own override mark.

Slider field

Blender factor slider · DialKit fill · Base UI Slider keyboard

Bounded values draw a full-height fill. Scrubbing maps the field width to the range; Home/End jump to bounds. Only use for values with a real range; unbounded transforms stay plain number fields.

Select

Base UI Select (alignItemWithTrigger)

Opens on press with the selected item over the trigger. ↑ ↓ Enter Space open; typeahead resets after 500 ms; Esc returns focus to the trigger. Build this from the Menu component, not RmlUi's <select>, whose popup properties cannot be restyled.

Checkbox · Switch

Base UI Checkbox / Switch

Properties use checkboxes (Blender). Space toggles. The switch is reserved for settings that apply immediately outside the document.

Color field

DialKit color popover · Blender swatch

The swatch opens a picker with a saturation/value plane, hue track and hex entry. Dragging updates live; closing commits one change; Esc restores the original. Zero alpha shows an empty swatch. RmlUi draws the plane and hue track with the vertex-colored horizontal-gradient/vertical-gradient decorators, which need no shader support.

Text · Search

shadcn Input Group

Typed text uses the dark input surface; the editing state shows the ring. Search fields filter immediately; Esc clears then blurs.

Property row

Blender property split

Right-aligned labels in a 38% column; controls fill the rest. Rows are --h tall with --gap between them. Search matches highlight the label.

Panel

Base UI Collapsible · Blender panel

Independent collapsible groups; open state persists per component type. ⌘-click opens one and collapses the rest. The header shows an override count and a ⋯ menu. The chevron rotates in 140 ms; content does not animate height, so layout never lags input.

Tree row

Blender Outliner

22 px rows: twisty, type icon, name, inline behavior icons, visibility and lock toggles. Active row uses --active-row; other selected rows use --selected. Click selects, ⌘-click toggles, Shift-click selects a range, double-click or F2 renames inline.

Context tabs

Blender Properties tabs · Base UI Tabs

A vertical icon strip chooses the Properties context. Tabs appear only when the subject has matching data. During property search, tabs without matches dim and tabs with matches show a dot.

Area header

Blender editor header

Every area starts with an editor-type menu, then editor menus, context, and trailing tools. Areas are non-overlapping splits resized by 4 px splitters; any area can host any editor. Ctrl Space maximizes the area under the pointer. This replaces ImGui docking.

Menu · Menubar · Context menu

Base UI Menu, Menubar, ContextMenu

Opens on pointer down. While a menubar menu is open, hovering another trigger switches immediately; ← → move between menus. Submenus open after 100 ms hover or →. Typeahead 500 ms. Tab closes. data-highlighted is separate from hover; disabled items can be highlighted but not activated. Checkable items reserve an indicator column. Popups enter with 140 ms opacity and 0.97 scale from their trigger; keyboard opens are instant.

Tooltip

Base UI Tooltip + Provider · Blender

500 ms rest delay, then instant within a 400 ms group window. Opens immediately on keyboard focus. A label and optional shortcut, plus a short description when the label alone does not explain the control or node.

Command

cmdk · Base UI Dialog

Focus stays in the input; the list uses an active descendant. Ranking ports command-score (continuous 1, word start 0.9, separator 0.8, jump 0.17). Groups order by their best match; selection tracks the item, not the index, and resets to the first result on each query. ↑ ↓, Ctrl N/Ctrl P, Enter. Pages push a breadcrumb chip; Esc or Backspace on an empty query pops. Pointer selection follows movement, not enter. The same component powers Quick Open, Add Object, Attach Behavior and Add Node.

Dialog

Base UI AlertDialog

Modal, focus trapped, initial focus on the primary action, Esc cancels. Used for Save / Discard / Cancel when closing a dirty document.

Node · Socket

Blender node editor

Header color encodes the node category; socket color encodes the data type. Exec sockets are diamonds; data sockets are circles, hollow when unconnected. Unbound inputs show inline number fields; bound inputs show their component field. Selected nodes use the viewport orange; the active node uses white. In RmlUi, nodes are elements inside a transformed stage and wires are a custom element that emits geometry.

Status hints

Blender status bar

The status bar lists the actions available under the pointer and reports the last operation. Modal operations replace the hints with their own keys and live deltas.
